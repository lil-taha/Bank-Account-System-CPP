# 🏦 Bank Account System (C++)

A console-based banking application developed in C++ as part of the Programming Fundamentals coursework. This program simulates core banking operations with a secure login system, balance tracking, deposits, withdrawals, and loan features.

## ✨ Features
* **Secure Authentication:** Username and PIN login system (`admin` / `1122`).
* **Deposit Money:** Add funds to the account with positive-amount validation.
* **Withdraw Money:** Withdraw funds with sufficient balance checks.
* **Check Balance:** View current account balance in real-time.
* **Take Loan:** Request and add loan amounts directly to the account balance.
* **Interactive Menu:** Clean loop-driven menu interface using `switch` statements.
